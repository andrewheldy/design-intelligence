Design Intelligence

Governed design agents, not prompt sprawl.

A compact operating layer routes the right skill, agent, verification check, and handoff artifact for each project.

Operating pieces

01

Registry

One source of truth for skill status, license posture, recommended use, and conflicts.

02

Agents

Director, implementer, curator, integrator, and reviewer roles with clear output contracts.

03

Harness

Local checks prove that manifests, scenarios, skills, registry evidence, and connections line up.

04

Connections

Non-secret records identify external tools and approval points without storing credentials.

Default route

  1. ScopeOrchestrator classifies the request and chooses the smallest complete package.
  2. AuthorizeRegistry and AGENTS rules decide which skills and agents can be used.
  3. BuildImplementation happens only where the request needs real code or artifacts.
  4. VerifyHarness, browser, document, PDF, accessibility, and motion checks run as applicable.
  5. Hand offThe user gets a short explanation, reusable files, and unresolved decisions.
